# Business-Project-in-AI-ML

This Project is a ML powered Live IPL score predictor made with help of Random Forest Regression model. The dash framework is used for making the Web UI which is uer interactive.
User can input real time match inputs and the final predicted score will be displayed on the Web UI.

The Repository consist of:

1. A jupyter notebook .ipynb file where the model is trained
2. A app.py file which is the main web ui file where the dashboard code is written

The repository is public and can be used for academic purposes.
